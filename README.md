# 📈 Stock Portfolio Tracker (Python)

## 📌 Description

The Stock Portfolio Tracker is a Python-based application developed as part of the CodeAlpha Internship. It helps users manage their stock investments by tracking portfolio performance, calculating total value, and analyzing profit or loss.

---

## 🚀 Features

* Add and manage multiple stocks
* Track quantity and price of each stock
* Calculate total portfolio value
* Profit/Loss analysis
* Simple and user-friendly interface

---

## 🛠️ Technologies Used

* Python
* (Optional: Pandas / APIs if used)

## ▶️ How to Run

1. Clone or download the repository
2. Open terminal in the project folder
3. Run the program:

   ```bash
   python main.py
   ```

## 📂 Project Structure

* main.py → Main application logic
* portfolio.py → Portfolio management (if used)
